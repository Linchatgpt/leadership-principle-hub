# AI working rules

Read PRODUCT.md, TASK.md, HANDOFF.md, USER_GUIDE.md, and WORK_LOG.md before work.
Do not modify reference_materials/source_book/inbox originals.
Use verified reference_materials/source_library Markdown instead of repeatedly reading full books.
Do not edit generated HTML as the only source of truth.
Put generated chapter and integration HTML in the project root and follow the configured output_prefix naming pattern.
Use root index.html as the entry point; link every learner-facing page from it and make every top-left brand return to it.
Update TASK.md, HANDOFF.md, and WORK_LOG.md before stopping; update PRODUCT.md and USER_GUIDE.md when behavior or usage changes.
Only mark verified work complete.

## 使用者指定的網站驗證規則

- 凡修改網站、管理編輯器或前端互動功能，必須先在 Chrome 實際操作測試成功，再向使用者回報。
- 未完成 Chrome 實測前，不得宣稱功能已完成或正常。
- 每章「深入閱讀」的實質中文內容至少 5,000 字；完成前必須實際計算渲染文字字數，未達標不得回報完成。
- 使用者頁面內容不得提到「本書」、書名或作者；來源資訊只保留在內部研究與交接文件。
