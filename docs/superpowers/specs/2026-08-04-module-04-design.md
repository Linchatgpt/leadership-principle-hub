# Module 04 設計規格：挑戰流程

## 目標

將「挑戰流程」設計成一個以流程改善與效率提升為主題的學習模組，協助台灣企業主管把反覆救火轉成可觀察的流程假設，並在一週內完成一個低風險、可回看的小實驗。

## 核心學習路徑

看見卡點 → 找出假設 → 設計小實驗 → 從證據修正。

## 內容與互動

- Hero 儲存「開始前，先想一想」判斷。
- 深入閱讀前置三張章節專屬卡片、四點導讀與三題情境快問。
- 深入閱讀六段原創文章，渲染中文實質文字以 5,000 字以上為目標。
- 案例聚焦客服、業務與產品的需求流程，保留速度、品質、權責與關係的拉力。
- 自評四構面：看見流程訊號、拆解問題與假設、設計低風險實驗、從結果學習與調整；12 題、每構面 3 題。
- 工作紀錄與行動承諾沿用新版 `.head + .simple-record` 契約。

## 視覺方向

延續全站深墨綠與暖紙色，只新增偏橙的「實驗標記色」。以細線節點與「觀察／假設／證據」標籤表達流程改善，不建立另一套頁面外觀；手機版流程節點垂直排列。

## SEO

加入 Module 04 專屬 title、description、canonical、Open Graph 與 JSON-LD；文案自然涵蓋流程改善、工作流程優化、效率提升、流程問題診斷與小型改善實驗。 learner-facing SEO 不提來源書籍、書名或作者。

## 驗收

通過技能結構驗證、渲染字數與 Markdown 結構檢查、Python／JavaScript 檢查，並在 Chrome 實測閱讀入口、自評缺答與結果、快問保存／清除、工作紀錄保存、行動承諾、桌面與 390px 手機版。
